# SplitEZ

- SplitEz is a web application built with Django that simplifies group expense tracking.
- Users can create or join groups, add expenses, and automatically split costs among members.
- The app calculates debts, allows users to mark them as paid, and provides a QR code for easy group joining.
- With a clean, responsive interface powered by Tailwind CSS, SplitEz makes managing shared expenses effortless.
